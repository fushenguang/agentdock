# Changelog

## 0.1.0

### Added

- Initial child-oriented TanStack Start template.
- Three prebuilt Astryx themes: `kids-sprout`, `kids-explorer`, and `kids-creator`.
- Age-profile capability model with `sprout`, `explorer`, and `creator`.
- SSR-safe coarse profile cookie and `ChildExperienceProvider`.
- Child shell, page header, action card, choice, progress, state, illustration, read-along, guardian gate, and profile switcher components.
- Localized English and Simplified Chinese child-facing examples.
- Child safety, age profile, and reference provenance documentation.
- Theme freshness, contrast, asset provenance, Astryx boundary, accessibility, visual regression, SSR, and bundle-budget checks.
