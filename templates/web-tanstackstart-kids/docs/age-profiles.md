# Age Profiles And Capability Model

The template separates the visual theme from developmental support. `sprout`, `explorer`, and `creator` are initial presets, not hard-coded feature branches.

| Capability          | Sprout      | Explorer        | Creator                        |
| ------------------- | ----------- | --------------- | ------------------------------ |
| Intended age        | 3–5         | 6–8             | 9–12                           |
| Minimum target      | 56px        | 48px            | 44px                           |
| Base text           | 20px        | 18px            | 16px                           |
| Density             | airy        | comfortable     | focused                        |
| Max primary choices | 3           | 5               | 7                              |
| Navigation depth    | 1           | 2               | 3                              |
| Reading support     | audio-first | mixed           | text-first                     |
| Motion              | gentle      | playful         | standard                       |
| Guidance            | always      | contextual      | on-demand                      |
| Confirmation        | explicit    | confirm-or-undo | undo-first                     |
| Timeout             | disabled    | extended        | standard only when non-harmful |

## Rules

- Feature components consume capabilities, not raw age or profile labels.
- Product teams may override individual capabilities.
- Precise age is not stored by the template.
- Older profiles must reduce infantilizing decoration and increase autonomy.
- A lower reading level is not the same as lower ability or lower intelligence.
- Every profile must retain the same task semantics; only support and presentation change.
