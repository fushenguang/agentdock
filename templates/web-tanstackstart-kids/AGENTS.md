# AgentDock web-tanstackstart-kids — Agent Execution Boundaries

> For AI coding agents working in a project generated from the child-oriented TanStack Start template.

Read `LLM.md`, `DESIGN.md`, `docs/age-profiles.md`, and `docs/child-safety.md` before making non-trivial changes. This file defines execution boundaries; `LLM.md` defines how to build within them.

## May Execute Autonomously

- `pnpm install`, `pnpm dev`, `pnpm dev:prepare`, `pnpm build`, `pnpm check`, `pnpm check:full`, `pnpm check-types`, `pnpm lint`, `pnpm format`, `pnpm format:check`, `pnpm test`, `pnpm test:a11y`, `pnpm test:visual`
- `pnpm theme:build`, `pnpm theme:check`, `pnpm assets:check`, `pnpm boundaries:check`, `pnpm budgets:check`
- `pnpm generate-routes`
- `pnpm db:generate`, `pnpm db:migrate`, `pnpm db:studio`
- Creating or editing files inside `src/core`, `src/features`, `src/infra`, `src/routes`, `src/components`, `docs`, and `test`
- Updating template documentation and tests

## Must Pause And Confirm

- Any `git push`, force push, package publishing, or release operation
- Deleting tracked files or directories
- Adding a new top-level directory
- Adding or replacing a runtime UI, icon, font, animation, analytics, advertising, or tracking dependency
- Changing `openspec/config.yaml`
- Changing `pnpm-workspace.yaml`, `packageManager`, Node engine requirements, deployment entrypoints, or the child profile cookie contract
- Editing Supabase migrations after they have been applied to a shared environment

## Prohibited

- Forking, swizzling, patching, or copying Astryx core source
- Importing `animal-island-ui`, `naive-icons`, or historical assets from the reference project
- Storing precise age, birth date, precise location, or identifying child data by default
- Adding advertising, third-party behavioral tracking, public child profiles, social feeds, infinite reward loops, or pressure-based engagement mechanics by default
- Importing `infra/db/**` directly from `features/**`; use `core/repositories` and `infra/providers`
- Cross-feature imports that bypass a feature's public `index.ts`
- Importing `features/**` or `infra/**` from `core/**`
- Creating a feature directory without `__contract__.ts`
- Writing real secrets, API keys, tokens, or production database URLs
- Running `rm -rf` on tracked directories
- Bypassing hooks with `--no-verify`
- Editing `src/routeTree.gen.ts`; it is generated by `pnpm generate-routes`
- Editing generated theme `.js`, `.css`, or `.d.ts` artifacts by hand; edit theme source and run `pnpm theme:build`

## Architecture

```text
src/routes/       TanStack Start file routes
src/components/   Child experience, appearance, locale, and shared presentation
src/core/         Stable domain types and repository contracts
src/features/     Product behavior; each feature owns a contract and public index
src/infra/        Drizzle clients, schemas, repository implementations, provider wiring
```

Features are the primary implementation area. Data access flows through a repository contract and the provider in `src/infra/providers.ts`.

## UI And Experience Rules

- Astryx is the component and interaction kernel. Do not reimplement focus, selection, dialogs, validation, keyboard, ARIA, or announcements.
- Use semantic Astryx tokens. Do not hard-code theme colors, spacing, radius, shadow, or motion in feature components.
- Use `xstyle` for component-specific StyleX overrides and Astryx layout primitives before raw HTML.
- Child feature code consumes semantic capabilities from `useChildExperience()`. Do not branch on raw age numbers or `sprout`/`explorer`/`creator` strings in feature components.
- Preserve one primary action per meaningful region and keep child-facing copy short, concrete, and non-blaming.
- Add every user-facing string to all catalogs in `src/i18n/messages.ts` and resolve it with `useTranslator()`.
- Keep pages under the `/$locale` route layout.
- Use original SVG/CSS illustrations or assets with recorded provenance.
- Honor `prefers-reduced-motion`; never make motion or audio the only path to completion.
- Use `GuardianGate` for external, sensitive, or consequential actions.
- Run the `impeccable` review for non-trivial UI work.

## Verification

Run the narrowest useful check while iterating, then the full gate before finishing:

```bash
pnpm test
pnpm test:a11y
pnpm theme:check
pnpm assets:check
pnpm boundaries:check
pnpm check-types
pnpm lint
pnpm format:check
pnpm build
pnpm check
pnpm check:full
```

`pnpm check` is the production acceptance command. `pnpm check:full` also requires visual snapshots and bundle budgets.
