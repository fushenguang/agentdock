`roadmap.yaml` at the repo root is the human-owned source of truth. This template does not
include automated roadmap-page generation (that tooling — `openspec-docs-sync` — is specific to
the `web-nextjs` template; see the template's `design.md` for why it was left out here).

Note that adding a skill does **not** need a roadmap entry — this roadmap tracks
infrastructure/contract direction for the registry itself, the same scope `openspec/config.yaml`
narrows proposals to. Edit `roadmap.yaml` directly and update this page by hand if you want the
docs site to reflect it.
