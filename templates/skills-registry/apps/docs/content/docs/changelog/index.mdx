This template does not include automated changelog generation (that tooling —
`openspec-docs-sync` — is specific to the `web-nextjs` template and was deliberately left out
here; see the template's `design.md` for why). Archived `openspec/changes/` entries are
infrastructure/contract changes only (manifest schema, gate rules, docs structure) — adding a
skill never produces one.

Maintain this page by hand as you archive changes, or link directly to
`openspec/changes/archive/` in your git history.
