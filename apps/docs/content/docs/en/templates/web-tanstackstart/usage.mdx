# Usage

## Create A Project

The CLI derives data-layer choices from the template metadata. `web-tanstackstart` defaults to SQLite:

```bash
npx @cogito.ai/cli init \
  --name my-internal-app \
  --template web-tanstackstart \
  --data-layer sqlite \
  --pm pnpm
```

Use `--data-layer supabase` to generate an environment template for Supabase Postgres. The selected provider appears in `.env.example` as `DATA_PROVIDER`.

The template supports pnpm `>=10.34.5 <13` and recommends 12.4.1. Generated projects do not write an exact `packageManager` pin, so supported versions do not trigger automatic version switching. The CLI still enforces pnpm-only generation.

### Embed In An Existing pnpm Workspace

When the target directory matches an existing `pnpm-workspace.yaml#packages`, the CLI uses workspace-member mode by default:

```bash
npx @cogito.ai/cli init \
  --name my-internal-app \
  --template web-tanstackstart \
  --dir apps/my-internal-app \
  --mode auto
```

The workspace member has no local `pnpm-workspace.yaml`, `pnpm-lock.yaml`, `.npmrc`, `packageManager`, or `engines.pnpm`. The workspace root owns dependency resolution and installation policy. The CLI writes `.agentdock/workspace.json` and prepends workspace instructions to `AGENTS.md`, including `pnpm install` from the root and `pnpm --filter <package> check` for project validation.

Root `allowBuilds` is never modified automatically. Apply `requiredRootChanges` from the JSON result and resolve `rootConfigConflicts` before running root `pnpm install`.

## Install And Run

Standalone projects support pnpm 10.34.5–12.x. If the local version is older than 10.34.5, update it or use the recommended npx command:

```bash
pnpm self-update 10.34.5
# Recommended
pnpm self-update 12.4.1
# Without changing the global version
npx --yes --registry=https://registry.npmjs.org pnpm@12.4.1 install
```

```bash
cd my-internal-app
cp .env.example .env
pnpm install
pnpm dev
```

`pnpm dev` applies pending SQLite migrations automatically before Vite starts. The production `pnpm start` command does not migrate implicitly; run migrations explicitly during deployment.

Open `http://localhost:3000`. The root redirects to the default Simplified Chinese locale at `http://localhost:3000/zh-CN`. The reference feature is available at `/zh-CN/hello`.

The shell includes appearance and language switchers. Appearance preferences persist in a first-party cookie so SSR can render the saved theme without a flash; language is represented by the URL prefix (`/zh-CN` default, `/en` alternate).

## Database Commands

```bash
pnpm db:generate
pnpm db:migrate
pnpm db:studio
pnpm db:generate:supabase
pnpm db:migrate:supabase
```

When repository behavior changes, update both dialect schemas and both repository implementations. With `DATA_PROVIDER=supabase`, development startup skips automatic SQLite migration and prints the explicit `pnpm db:migrate:supabase` command.

## Verification

```bash
pnpm format:check
pnpm lint
pnpm check-types
pnpm test
pnpm build
```

Run `pnpm check` for the complete gate. The route tree is generated before type-aware linting, type checking and build, so a clean checkout does not require a manual preparation step.

## Adding A Feature

Read `LLM.md` first. It contains the exact architecture rules, file recipes, import boundaries, and verification workflow for coding agents.

1. Add shared types or repository contracts under `src/core`.
2. Create `src/features/<name>/__contract__.ts`.
3. Keep the public API in `src/features/<name>/index.ts`.
4. Add a test next to the feature.
5. Add or update an infra repository only when persistence behavior changes.
6. Add the route under `src/routes/$locale/`.
7. Add user-facing strings to every catalog in `src/i18n/messages.ts`.
8. Follow `DESIGN.md` for UI and theme work, and apply the relevant Agent Skill.
9. Compose the shared `TemplateShell`, `PageContainer`, and `PageHeader` components.

Do not import `infra/db` from a feature. Use the provider and repository contract.

## Deployment Boundary

The default SQLite mode requires a persistent filesystem. Use a long-lived Node process or container with a mounted volume. Stateless/edge platforms are outside the first version's supported SQLite path; use Supabase Postgres when the application needs a remote database.
